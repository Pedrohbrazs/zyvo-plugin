# Zyvo

O plugin Zyvo permite usar o Zyvo, uma plataforma de marketing com IA para pequenas empresas, a partir do Claude. Com ele você consulta contas de redes conectadas, o status do agente de atendimento, o CRM, as campanhas e as pesquisas, e publica ou agenda posts nas redes.

## Como funciona

A conexão usa o servidor remoto do Zyvo com login OAuth. Nenhuma senha ou chave fica em arquivos do plugin.

Toda ação que escreve dados passa por uma prévia. O Claude mostra o que será feito e só executa depois da sua confirmação. Ações que gastam verba ou disparam mensagens para clientes pedem confirmação extra.

## Dados enviados

As consultas e as ações são enviadas ao servidor do Zyvo, na conta da empresa que você autorizou. O plugin não envia dados a terceiros.

## Requisitos

Uma conta ativa no Zyvo e permissão para a empresa autorizada.
